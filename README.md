# Python Course

<div dir="rtl">

دورهٔ **برنامه‌نویسی پایتون** به زبان فارسی، برای کسانی که هیچ تجربهٔ برنامه‌نویسی ندارند. این دوره ترم اول از یک مسیر شش ترمی است و در ۱۶ جلسهٔ دوساعته، از نصب محیط برنامه‌نویسی تا برنامه‌نویسی شیءگرا و یک پروژهٔ پایانی کامل را پوشش می‌دهد.

برای هر جلسه سه فایل وجود دارد:

- **نوت‌بوک درس** (پوشهٔ `sessions`): توضیحات کامل، مثال‌های اجراشده و تمرین‌های پایان جلسه
- **پاسخ تمرین‌ها** (پوشهٔ `solutions`): پاسخ پیشنهادی هر تمرین
- **اسلاید** (پوشهٔ `slides`): ارائهٔ پاورپوینت جلسه برای کلاس

## اجرا

ساده‌ترین راه، باز کردن نوت‌بوک‌ها در Google Colab با دکمهٔ **Open in Colab** بالای هر نوت‌بوک است. برای اجرا روی سیستم خودتان:

</div>

```bash
git clone https://github.com/keyvanmahmoudi/Python_Course.git
cd Python_Course
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook
```
